## 📝 Apple ID 注册简单过程

### 注册步骤

**官网地址**：https://account.apple.com/

1. 官网点击注册（推荐电脑端）
2. **注意地址一定要选择土耳其**
3. 接收邮箱这边最好选择非 QQ 邮箱
4. 其他信息可以随便写（年龄大于18）

### 地址生成工具

这边有比较方便的网站可以直接生成相关信息，直接按照这个进行填写即可：

**土耳其地址生成器**：https://1ktools.com/zh-cn/tools/developer/turkey-address-generator

### 注册技巧

- 号码可以选择国内号码
- **无需挂梯子**，不然不稳定
- 如果提示暂无法创建账号也没事，换一下浏览器或者切无痕多试试
- 实测都可以成功创建

### 登录设备

然后接下来就是比较重要的一步了，那就是设备登录账号：

1. 首先需要先在 App Store 的历史账号退出
2. 复制下面的这个编码，在浏览器（Safari）中打开切换地区（都是为了伪造清除缓存）：

   ```
   itms-apps://itunes.apple.com/WebObjects/MZStore.woa/wa/resetAndRedirect?dsf=143480&cc=tr
   ```

3. 切换成功的样子就是 App Store 的内部都是英文，然后再登录账号
4. 登录点开 Account 查看 Country 是否显示土耳其（土耳其语），是的话那就恭喜你成功注册且登录了
