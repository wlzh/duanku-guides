## 一、这到底是一条什么路子

先说清楚一个容易搞混的点：**这条路跟 edu（学生）邮箱一点关系都没有**，也不需要你是学生。

事情是这样的：X 上 @taiyanghere 发了一条推文，说 MLH（Major League Hacking，全球最大的学生黑客松联盟）正在办**Global Hack Week** 线上活动（2026年10月9–15日），活动里的一个挑战任务奖励是**免费 Cursor Pro 兑换码**——Cursor Pro 正常订阅是 20 美元/月。

玩法很简单，一共四步：

1. 注册一个**MyMLH** 账号（mlh.com 的统一账号）；
2. 报名这期 Global Hack Week 并完成签到（check-in）；
3. 去 cursor.com 注册一个 Cursor 账号（免费）；
4. 等**MLH 团队把 promo code 发到你的注册邮箱**，拿着码去 Cursor 的 Billing 页面手动升级到 Pro，再把 Dashboard 显示 Pro 的截图交回挑战页。

⚠️ 先打预防针（推文原作者自己也说了）：兑换码的**具体额度、是不是人人都有、要不要绑卡**，当时都没有明确说法。实测中兑换码是**活动方分批邮件发放**，不是报名完立刻就到，需要耐心等。我已经设了每 6 小时自动检查邮箱，码一到就自动兑换。

## 四、注册 MyMLH 账号

打开 https://www.mlh.com/signup，页面很简单：填邮箱 + 一个 Cloudflare「请验证您是真人」复选框 + Sign Up 按钮。

步骤截图**注意点

1. ：**不点验证框，Sign Up 按钮是灰的，点不了**。必须先把「请验证您是真人」点掉。**注意点 2（大坑）**：**不要用临时邮箱注册！** 实测用临时邮箱（mail.tm 这类）提交，页面直接报错：

> "Primary email identifier: We do not accept your email provider."

MLH 把临时邮箱域名整个拉黑了。老老实实换 Gmail/Outlook 等常规邮箱，一次过。**注意点 3**：Cloudflare 验证偶尔抽风——复选框明明显示「成功!」，点提交却报红字 "Turnstile verification failed. Please try again."（如下图）。别慌，这不是你的问题，**重新点一次验证框再提交**就行，第二次一般就过了。

## 五、邮箱验证 + 完善资料

提交后 MLH 会往你的邮箱发一封**6 位数字验证码**，去邮箱里找 MLH 的邮件，把码填回去就行（验证码一般几分钟内有效，过期了点重发）。

验证通过会进 "Welcome to MyMLH" 资料页，按顺序填完 3 个资料步骤：

1.**Demographics（人口统计）**：Gender（性别）*、Race or Ethnicity（种族）* 是必填的自由文本框，Pronouns（代词）选填。不想透露的话，三项都可以填 **"Prefer not to answer"**，实测能通过。
2.**Education（教育状态）**：有 "I'm not a student"（我不是学生）选项——**选它也能继续**，再次证明这活动不要求学生身份。
3.**生日**：必填的日期选择器，如实填就行（MLH 要确认年满 18 岁或有家长许可）。**注意点**：这三步是账号级别的资料，一次填完以后参加 MLH 别的活动不用再填。

---

## 六、报名问卷 + 签到

资料填完点进活动，会跳到**events.mlh.com** 的报名页，弹出主办方的**"Registration Questions"** 问卷，4 个必填项：
| 题目 | 怎么填（实测通过的版本） |
|---|---|
| Country of Residence（居住国）* | 下拉选 **China** |
| How did you hear about this event?（从哪知道的） | 下拉选**Twitter / X**（就是那条推文） |
| Which geographic region are you located in?（活动期间所在地区）* | 下拉选 **Asia Pacific (APAC)** |
| What's your GitHub username/handle?（GitHub 用户名）* | 填你的 GitHub handle |
下面还有**3 个必勾的同意复选框**：年满 18 岁（或有家长许可）、同意 MLH Code of Conduct、同意比赛条款和隐私政策——注册报名的标准动作，勾上才能提交。另外有**邮件订阅的可选项，默认不勾**，别手滑。

还有两项顺手提一句：GitHub Student Developer Pack 问你要不要，选**No**（跟前面"不是学生"保持一致）；还有个 swag（贴纸）邮寄须知的复选框是提交必填的，它只是告诉你"想收贴纸要另去 hackp.ac/address 填地址"，勾上不代表现在填地址。

全部提交后，报名页会明确显示**"You are checked in!"**，并出现 "Join online event" 按钮——看到这句，报名签到就成了。页面横幅会显示 "Hacktoberfest Oct 9th – 15th, 2026"。

## 七、注册 Cursor 账号

打开 https://cursor.com，点登录，会跳到**authenticator.cursor.sh** 认证页，选**"Continue with Google"**（用 Google 快捷登录最省事，不用记新密码）。**注意点（重要）**：Google 可能会觉得这次登录环境陌生，弹安全确认——往你的手机发推送，让你在**Gmail App 里点按一个数字**（实测是数字 16）来证明是本人在操作。**这一步必须你自己在手机上点**，自动化过不去。点完批准，OAuth 授权通过，就自动进 Cursor 仪表盘了。

进仪表盘确认两件事：左下角显示你的名字和**Free** 计划（实测显示 "Free (with X Premium+)"），并且有**"Upgrade to Pro"** 入口——**先别点**，等兑换码到了再用码升级。全程**不绑卡、不订阅付费**，纯免费账号。
