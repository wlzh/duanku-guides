### 什么是 eSIM？

第一次接触的同学补一课。eSIM 就是「电子 SIM 卡」，不需要实体卡片，也不需要邮寄——运营商发给你一个配置文件（profile），通常是一个二维码，手机扫一下就把号码装进去了，和插实体卡效果一样。这也是为什么这个羊毛人在国内也能薅：**卡是发到邮箱的，不用收快递。**

前提是你的设备支持 eSIM。iPhone 从 XS/XR 之后基本都支持（国行 iPhone 的 eSIM 支持情况特殊，请自行确认机型）；安卓这边 Google Pixel、三星旗舰等大多支持，国行安卓机大部分阉割了 eSIM，需要注意。再次强调，**别拿主力机薅**，原因见上面的警告。

## 准备工作：虚拟定位

### 方案一：Chrome DevTools 手动改定位（推荐，零安装）

这是门槛最低的方式——不装任何插件，用 Chrome 自带的开发者工具就能改定位，全程不到两分钟。**以下每一步都配有截图，跟着走就行。****第 1 步：打开 Chrome 无痕模式。** 无痕模式可以确保没有残留的缓存和 Cookie 干扰定位判断。**第 2 步：打开活动 URL，点击「拒绝」定位获取。** 先拒绝一次，等会儿改完定位再重新允许。

英国沃达丰福利网址：[https://www.vodafone.co.uk/sim-only/pay-as-you-go-sim/London](https://www.vodafone.co.uk/sim-only/pay-as-you-go-sim/London)

点击拒绝定位获取**第 3 步：打开 DevTools 的 Sensors 面板。** 按 `F12` 或 `Ctrl+Shift+I` 打开开发者工具，然后点右上角 `⋮` → `More tools` → `Sensors`。

DevTools 菜单路径：More tools → Sensors**第 4 步：设置自定义位置。** 在 Sensors 面板里，`Location` 下拉框选 `Custom location`：

Location 选 Custom location

然后填入以下参数：
| 参数 | 值 |
| --- | --- |
| Latitude（纬度） | `51.5074` |
| Longitude（经度） | `-0.1278` |
| Timezone（时区） | `Europe/London` |
| Locale（语言区域） | `en-GB` |
| Accuracy（精度） | `20` |
这组坐标就是伦敦市中心的经纬度，填进去后 Chrome 就会向网站报告你的位置在伦敦。

Sensors 面板填入伦敦坐标参数**第 5 步：现在可以允许位置权限了。** 刷新页面，这次当浏览器弹出位置权限请求时，点击「允许」。
