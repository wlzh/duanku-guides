# W-8表格签署

* 审核过程中可以把W-8先签了

* 选 `立即认证`

* 确认一遍个人信息

填写居住地址和联系方式

* 保存 `确认码`

* 选择 `W-8BEN` 表

* 这一页全部选否，点击 `continue`

* 填入税号信息

* 选 `Yes` ，填入相关信息

* 没有附加文件，继续 `continue`

* 全打钩

* 输入确认码

* 继续同意，签署完毕

选择同意，提交。
