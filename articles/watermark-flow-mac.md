## WatermarkFlow 是什么

**WatermarkFlow 是一个轻量的 macOS 菜单栏图片水印工具，面向高频截图、社交媒体配图和原创内容保护场景。** 它支持从剪贴板、拖放或文件导入图片，在非破坏式编辑会话中添加文字、X、YouTube 或自定义 Logo 水印，最终复制 PNG 或导出 PNG/JPEG。

它不是 Photoshop 的替代品，也不试图成为通用图片编辑器。它解决的是一个更具体的问题：当水印样式已经确定，如何把每次发布前的机械操作压缩到尽可能少。

## 传统加水印流程为什么低效

### 1. 工具启动和文件往返比编辑本身更耗时

一张截图可能只需要右下角放一个账号名，但传统流程要先落盘，再打开图片软件，最后导出并重新找到文件。WatermarkFlow 可以直接发现刚复制的图片，处理完成后又回到剪贴板，适合聊天、博客后台和社交平台之间的连续操作。

### 2. 同一品牌水印每次都要重新调

颜色、透明度、大小、角度、位置和 Logo 一旦反复手动设置，就容易出现视觉不一致。WatermarkFlow 支持保存自定义模板，并将某个模板设为快捷默认；编辑器最后选择和快捷默认互不覆盖，临时尝试不会破坏高频工作流。

### 3. 单个角标挡不住裁切转载

右下角水印容易被裁掉，但传统满屏水印又经常过密、影响阅读。WatermarkFlow 可以在“单个”和“满屏”之间切换，满屏模式采用错列平铺并提供 1 至 10 级密度。两种布局分别保存自己的颜色、透明度、大小、旋转和自动对比参数。

### 4. 深浅背景让固定颜色失效

白色水印遇到浅色背景会消失，黑色水印在暗部同样看不清。工具可按水印实际覆盖区域取样，选择“仅文字”或“文字 + 背景”的自动对比，并提供柔和、标准和强烈三档。关闭后仍会恢复手动色值，不会永久改乱模板。

## 一个典型工作流

假设你刚截了一张产品界面，要发到 X、微信群和博客：

1. 截图后让图片进入系统剪贴板。
2. 按默认全局快捷键 `Option + Command + W`。
3. WatermarkFlow 载入图片并应用快捷默认模板。
4. 需要防裁切时切换到满屏，按内容密度调整平铺级别。
5. 背景复杂时开启自动对比，检查文字和 Logo 是否清晰。
6. 点击“生成并复制”，直接回到发布应用粘贴。

对偶尔处理一张图的人，这只是少开一个应用；对每天发布几十张截图的人，它减少的是一整条重复操作链。

## 模板、画布和输出设计

WatermarkFlow 内置 X 与 YouTube 示例模板，也支持创建“Logo + 文字”组合模板。每张图片在当前会话中保留原图和水印参数，预览调整不会反复压缩源图；最终输出才扁平化。

大图采用轻量预览，但生成时保持原始像素。放大后可以拖动画布或用触控板滚动检查细节，水印相对于原图的位置不会因为查看方式变化。误选模板时可以移除当前水印后恢复，也可以直接切换模板替换，不会层层叠加。

## 下载、安装与使用

WatermarkFlow 支持 macOS 13 及以上版本，以及 Apple Silicon 和 Intel Mac。普通用户可前往 [WatermarkFlow GitHub Releases](https://github.com/wlzh/watermark-flow-mac/releases) 下载 Universal macOS 压缩包。

当前发布包为 ad-hoc 签名，尚未使用 Developer ID 签名和 Apple 公证。首次启动时，应按照项目的安装文档处理系统安全提示，不要把“开源”误解为已完成 Gatekeeper 公证。

从源码构建需要 Swift 5.10 或更高版本：

```sh
git clone https://github.com/wlzh/watermark-flow-mac.git
cd watermark-flow-mac
./scripts/test-all.sh
./scripts/install-local.sh
```

安装后建议先完成三项设置：建立自己的模板、指定快捷默认模板、确认剪贴板策略。剪贴板策略可关闭，也可设为仅空画布自动载入或始终自动替换；应用自己生成的复制结果不会再次触发处理。

## 常见问题

### WatermarkFlow 会修改原图吗？

编辑过程保留当前会话的原图和水印参数，输出时生成扁平图片。为了避免误覆盖，重要原文件仍应单独保留。

### 支持 Logo 和文字一起使用吗？

支持。可以创建新的 Logo + 文字模板，不必修改已有模板；模板可保存并设为快捷默认。

### 满屏水印能单独调整吗？

可以。单个与满屏布局分别保存样式参数，满屏还拥有独立密度，切换布局时会恢复各自设置。

### 图片会上传到服务器吗？

项目定位为原生本地处理工具，仓库功能说明没有账户或云端处理链路。你也可以直接审查 MIT 开源代码和构建脚本。
