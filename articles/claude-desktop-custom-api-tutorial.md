## 操作步骤总结

1. 正常安装 Claude Desktop
2. 首次打开，**不登录**。利用键盘导航或快速点击，打开菜单 → Help → Troubleshooting → Enable Developer Mode
3. 菜单 → Developer → Configure third-party inference
4. 配置中转地址和 API key，应用设置即可

## 关键注意事项

- **HTTPS 是必须的**：本地测试请将 localhost 改为 127.0.0.1，或使用域名并启用 https
- **Gateway 支持**：中转网关必须支持 v1/models 接口才能正确列出模型
- **子代理模型兼容性**：桌面版对子代理（如 Haiku）的模型映射适配不太行，可能会有找不到模型的情况
- **跳过登录技巧**：可以寻找 Skip login-mode chooser 选项，或刚打开客户端时快速点击左上角菜单进行配置
